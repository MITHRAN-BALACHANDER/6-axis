# Deploying to Render

This project is configured to deploy both the Django Backend and React Frontend to Render using a Blueprint (`render.yaml`).

## Prerequisites

1.  **Git Repository**: Ensure your project is pushed to GitHub or GitLab.
2.  **Render Account**: Create an account at [render.com](https://render.com).
3.  **MongoDB Atlas**: You are already using MongoDB Atlas. You will need your `MONGO_DB_USERNAME` and `MONGO_DB_PASSWORD`.

## Steps

### 1. Push Changes
Ensure you have committed and pushed the latest changes, specifically:
- `render.yaml` (Updated configuration)
- `backend/requirements.txt` (Fixed dependencies)
- `backend/robotics/settings.py` (Production ready settings)

### 2. Create New Blueprint Instance on Render
1.  Go to your [Render Dashboard](https://dashboard.render.com).
2.  Click **New +** and select **Blueprint**.
3.  Connect your repository (`6-axis`).
4.  Render will automatically detect the `render.yaml` file.

### 3. Configure Environment Variables
Render will ask for the values of variables defined with `sync: false` in `render.yaml`.
You **MUST** enter these values manually:

| Key | Value |
| :--- | :--- |
| `MONGO_DB_USERNAME` | Your MongoDB Username (from your local `.env`) |
| `MONGO_DB_PASSWORD` | Your MongoDB Password (from your local `.env`) |

**Note**: `SECRET_KEY` will be auto-generated by Render.
`VITE_API_URL` is configured to point to the backend URL automatically.

### 4. Deploy
Click **Apply** or **Create Services**. Render will start deploying:
- **six-axis-backend**: The Django app (Web Service).
- **six-axis-frontend**: The Vite app (Static Site).

### 5. Verify
Once deployed:
1.  Check the Backend URL (e.g., `https://six-axis-backend.onrender.com/admin`) to see if it loads.
2.  Check the Frontend URL (e.g., `https://six-axis-frontend.onrender.com`).
3.  Try logging in to ensure the database connection works.

## Troubleshooting

- **Database Errors**: Check the Render logs for `six-axis-backend`. If you see connection errors, verify your `MONGO_DB_USERNAME` and `MONGO_DB_PASSWORD` were entered correctly (no special characters that require extra escaping, although `quote_plus` in settings handles most).
- **CORS Errors**: If the frontend cannot talk to the backend, check the Browser Console. Ensure `CORS_ALLOWED_ORIGINS` in `settings.py` includes your frontend URL. We have set this up to auto-configure, but double-check if the URL scheme changes.
